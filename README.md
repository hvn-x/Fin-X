> ### Description
> Fin-X is a Jellyfin 12 ONLY theme that provides a clean frosted glass-like look to your Jellyfin along with red, gray, and (soon) gold accents. This theme is still being developed, so please allow time for when a new update releases and unstyled pages to be styled.

## Gallery:
Will be added when I feel productive

## Installation:

Go to Dashboard > Branding > Custom CSS Code

### Main Stylesheet
```css
@import url("https://cdn.jsdelivr.net/gh/hvn-x/Fin-X@main/THEME/theme.css");
```
### Media Bar Stylesheet
[Media Bar Plugin](https://github.com/IAmParadox27/jellyfin-plugin-media-bar)
```css
@import url("https://cdn.jsdelivr.net/gh/hvn-x/Fin-X@main/THEME/Paradox27-MediaBar.css");
```
