# Fin-X | <img src="/ASSETS/Fin-Xlogo.png" alt="Fin-X" width="13.5%" align="center"/>

> ### Description
> Fin-X provides a clean frosted glass-like look to your Jellyfin along with red & gray accents. This theme is still being developed, so please allow time for when a new update releases and unstyled pages to be styled. 


## Installation:
```css
@import url("https://cdn.jsdelivr.net/gh/hvn-x/Fin-X@main/THEME/theme.css");
@import url("https://cdn.jsdelivr.net/gh/hvn-x/Fin-X@main/THEME/Paradox27-MediaBar.css");
```
